- 작성일: 2026-11-10
- 상태: 승인됨(1~4부 대화로 확인, 2026-11-10 사용자 구현 지시)
- 관련 문서: `2026-11-09-workout-log-design.md`(앱), `2026-11-09-exercise-videos-design.md`(영상)

## 1. 목적과 범위

### 목적

휴대폰을 바닥에 두고 화면을 보지 않아도 음성과 삐 소리로 따라 할 수 있는 인터벌 타이머를 만든다. 사용자가 처음 제안한 형태는 "준비 10초, 운동 30초, 휴식 10초, 3세트"다.

### 이번 범위 (사용자 선택: B)

- 기본 인터벌: 준비 → (운동 → 휴식) × 세트
- 서킷: 운동 구간마다 종목을 정하고, 운동 중에는 그 종목의 따라하기 영상, 휴식 중에는 다음 종목을 보여주고 말해 준다
- 기본 프리셋 6개와 이름 붙인 내 타이머 저장(백업에 포함)
- 기기 음성 합성(한국어) + 삐 소리, 화면 꺼짐 방지
- 아래쪽 탭에 "타이머" 추가
- 새 분류 `#케틀벨`과 `#덤벨`, 그 종목들과 따라하기 영상(6절)

### 하지 않는 것

- 타이머 결과를 운동 기록에 자동으로 남기기(선택지 C)
- EMOM, 근력 세트 휴식 타이머 같은 다른 형식
- 미리 녹음한 음성 파일
- 화면이 꺼진 상태나 다른 앱 사용 중의 소리(웹 앱은 화면이 잠기면 멈춘다)
- 음성·삐 소리 켜기/끄기 설정 저장(실행할 때마다 기본은 켜짐)

### 성공 기준

1. 기본 프리셋(10/30/10 × 3)이 2분 동안 진행되고, 정해진 시점에 음성과 삐 소리가 한 번씩 난다.
2. 다른 앱에 갔다 오거나 화면이 잠깐 멈춰도 남은 시간이 실제 흐른 시간과 맞는다.
3. 서킷은 운동 중에 그 종목 영상을, 휴식 중에 다음 종목과 영상을 보여준다.
4. 내 타이머를 저장·편집·복사·삭제할 수 있고, 백업 내보내기 → 가져오기로 그대로 복원된다.
5. 기존 사용자 데이터에도 새 기본 종목이 나타나고, 덤벨컬은 `#덤벨`로 옮겨 보인다.
6. 앱 테스트·린트·빌드와 영상 프로젝트 테스트가 통과하고, 새 종목 영상이 모두 만들어진다.

## 2. 타이머 구성과 저장

### 값

| 항목 | 범위 | 기본값 |
|---|---|---|
| 이름 | 앞뒤 공백을 뺀 1~30자 | "내 타이머" |
| 준비 `prepSec` | 정수 0~600 | 10 |
| 운동 `workSec` | 정수 5~3600 | 30 |
| 휴식 `restSec` (운동 사이) | 정수 0~3600 | 10 |
| 세트·라운드 `rounds` | 정수 1~50 | 3 |
| 라운드 사이 휴식 `roundRestSec` | 정수 0~3600 | 60 (서킷일 때만 쓴다) |
| 종목 `exerciseIds` | 0~20개, 중복 없음 | 비어 있음 |

```ts
type TimerPlan = {
  id: string
  name: string
  prepSec: number
  workSec: number
  restSec: number
  rounds: number
  roundRestSec: number
  exerciseIds: string[]
}
type Store = { version: 1; exercises: Exercise[]; workouts: Workout[]; timers?: TimerPlan[] }
```

- `timers`는 선택 필드다. 예전 데이터와 백업은 그대로 읽히고(타이머 없음), 새 백업에는 타이머가 들어간다.
- 참조 무결성: 타이머의 `exerciseIds`는 모두 있는 종목이어야 한다(`checkReferences`가 기록과 함께 검사한다).
- 직접 추가한 종목이 타이머에 쓰이고 있으면 삭제할 수 없다(기록에 쓰인 경우와 같은 규칙). 숨긴 종목은 타이머에 그대로 남고 실행된다.

### 진행 순서(구간 펼치기)

- 종목이 없으면 기본 인터벌: `준비 → 운동 → 휴식 → 운동 → … → 운동`. 운동은 `rounds`번, 마지막 운동 뒤에는 휴식이 없다.
- 종목이 N개면 서킷: `준비 → [종목1 → 휴식 → … → 종목N] → 라운드 휴식 → [종목1 → …] … → 종목N`. 라운드 안 종목 사이에는 `restSec`, 라운드 사이에는 `roundRestSec`, 마지막 종목 뒤에는 휴식이 없다.
- 길이가 0초인 구간(준비 0, 휴식 0)은 만들지 않는다.
- 예: 기본값 = 10 + 30×3 + 10×2 = 120초. 전신 서킷 = 10 + (4×40 + 3×20)×3 + 60×2 = 790초(약 13분).

### 기본 프리셋 (코드에 내장, 고칠 수 없고 "복사해서 내 타이머로"만 된다)

| ID | 이름 | 준비/운동/휴식 × 세트 | 라운드 휴식 | 종목 |
|---|---|---|---|---|
| preset-basic | 기본 인터벌 | 10/30/10 × 3 | – | – |
| preset-tabata | 타바타 | 10/20/10 × 8 | – | – |
| preset-hiit-beginner | HIIT 초급 | 10/30/30 × 8 | – | – |
| preset-hiit-intermediate | HIIT 중급 | 10/40/20 × 8 | – | – |
| preset-full-body | 전신 서킷 | 10/40/20 × 3 | 60 | 맨몸 스쿼트, 푸시업, 플랭크, 버피 |
| preset-core | 코어 서킷 | 10/30/15 × 3 | 45 | 크런치, 레그레이즈, 데드버그, 마운틴 클라이머 |

## 3. 진행 방식

### 시간 계산

- 실행 상태는 "시작 이후 흐른 실제 시간(ms)"만 가진다. 실행 중에는 `performance.now()` 차이를 더하고, 일시정지 중에는 더하지 않는다.
- 지금 구간과 남은 초는 흐른 시간에서 순수 함수로 계산한다(`positionAt`). 1초마다 숫자를 빼는 방식이 아니어서 화면이 멈췄다 돌아와도 시간이 밀리지 않는다.
- 남은 초는 올림으로 보여준다(구간 시작에 30, 끝나기 직전에 1).

### 안내 시점

| 시점 | 음성 | 삐 소리 |
|---|---|---|
| 준비 시작 | "준비하세요"(서킷이면 "첫 운동은 스쿼트") | – |
| 운동 시작 | "시작"(서킷이면 "스쿼트 시작") | 긴 삐 |
| 마지막 라운드의 첫 운동 시작 | 앞에 "마지막 라운드" | – |
| 운동 절반(운동 20초 이상) | "절반" | – |
| 휴식 시작 | "휴식"(다음 종목이 있으면 "휴식. 다음은 푸시업") | – |
| 라운드 휴식 시작 | "라운드 휴식. 다음은 2라운드" | – |
| 모든 구간의 마지막 3초(구간 4초 이상) | "3", "2", "1" | 짧은 삐 |
| 끝 | "운동 끝. 수고하셨습니다" | 긴 삐 |

- 안내는 "직전 확인 시점 < 안내 시점 ≤ 지금"인 것만 낸다(`cuesBetween`). 그래서 각 안내는 한 번만 난다.
- 직전 확인에서 1.5초 넘게 지났으면(다른 앱에 갔다 옴) 그사이 안내는 버리고 지금 구간부터 이어간다.
- 새 음성은 앞의 음성을 끊고 말한다(밀려서 늦게 나오지 않게).

### 조작

- 일시정지 / 계속
- 다음 구간: 지금 구간 끝으로 건너뛴다. 마지막 구간이면 끝낸다.
- 이전 구간: 구간 시작 후 2초 안이면 앞 구간 시작으로, 아니면 지금 구간 시작으로.
- 종료: 진행 중이면 확인 창을 띄운다.
- 건너뛴 구간의 안내는 내지 않고, 새 구간의 시작 안내만 낸다.

## 4. 화면

- 아래쪽 탭: 기록 · 달력 · **타이머** · 요약 · 설정.
- `/timer` 목록
  - 맨 위에 진행 중인 타이머가 있으면 "이어하기"를 보여준다.
  - "+ 새 타이머", 내 타이머 목록, 기본 프리셋 목록.
  - 줄마다 요약(예: `40초 운동 · 20초 휴식 · 3라운드 · 4종목 · 약 13분`)을 보여준다. 누르면 시작/편집/복사/삭제를 펼친다(프리셋은 시작/복사).
- `/timer?edit=<id|new>` 편집
  - 이름, 준비·운동·휴식·세트·라운드 휴식 숫자 입력(−/+ 버튼, 초는 5씩, 세트는 1씩).
  - 종목 목록: "+ 종목 추가"는 기존 종목 선택 창(여러 개 선택·중복 막기)을 쓴다. ↑ ↓로 순서, ✕로 빼기.
  - 총 시간 미리보기, 저장/삭제. 범위를 벗어난 칸은 빨간 테두리와 범위 안내, 고칠 때까지 저장을 막는다.
- `/timer?run=<id>` 실행(화면 전체, 아래쪽 탭을 가린다)
  - 라운드 `2 / 3`, 종목 `3 / 4`, 구간 이름(준비/운동·종목명/휴식), 아주 큰 남은 시간, 구간 진행 막대, 전체 남은 시간.
  - 배경색: 준비 = 코어 노랑, 운동 = 근력 빨강, 휴식·라운드 휴식 = 스트레칭 초록(앱 분류 색).
  - 서킷: 운동 중에는 그 종목 영상, 휴식 중에는 "다음: 푸시업"과 다음 종목 영상. 기본 인터벌은 영상 없이 숫자만.
  - [◀ 이전] [⏸ 일시정지/▶ 계속] [다음 ▶], 음성·삐 소리 켜기/끄기, [종료].
  - 끝나면 "운동 끝 · 총 13분"과 [다시 시작] [닫기].
  - 휴대폰의 뒤로 가기는 막을 수 없으므로 실행 화면을 닫을 때(뒤로 가기·주소 변경) 타이머를 일시정지하고, 목록의 "이어하기"로 이어간다. 진행 상태는 앱 안 메모리(모듈 상태)에 두며 새로고침하면 사라진다.

## 5. 오류 처리

| 상황 | 동작 |
|---|---|
| 입력값 범위 밖 | 칸에 빨간 테두리와 범위 안내, 저장 막기 |
| 저장 실패 | "저장하지 못했습니다", 입력 유지 |
| 음성 합성 미지원 또는 한국어 음성 없음 | "음성 안내를 쓸 수 없어 삐 소리만 냅니다", 음성 켜기 막기 |
| 소리 재생 막힘 | 소리는 "시작" 버튼을 누를 때 준비한다(브라우저 정책) |
| 화면 꺼짐 방지 미지원·거부 | "화면이 꺼지면 타이머가 멈출 수 있습니다". 화면이 다시 보일 때 다시 요청 |
| 없는 타이머 주소 | "타이머를 찾을 수 없습니다"와 목록으로 가는 링크 |
| 저장소가 준비되지 않음·손상 | 기존 `StoreGate` 규칙을 따른다(타이머 쓰기도 막힘) |

### 기존 데이터에 새 기본 종목 채우기

기본 종목은 앱을 처음 열 때 한 번 복사되므로, 코드에 종목을 더해도 이미 쓰던 데이터에는 나타나지 않는다. 저장소를 불러올 때(`load`, `replaceAll`) 다음을 한다(`syncSeedExercises`, 순수 함수).

- 저장된 데이터에 없는 기본 종목 ID는 끝에 더한다. 단 같은 이름(공백·대소문자 무시)의 종목이 이미 있으면 더하지 않는다(사용자가 직접 만든 종목을 존중).
- 이미 있는 기본 종목은 분류만 코드에 맞춘다(덤벨컬 → #덤벨). 이름·측정 방식·숨김은 바꾸지 않는다(측정 방식을 바꾸면 기록과 맞지 않게 된다).
- 바뀐 것이 있을 때만 저장한다. 손상·새 버전 상태에서는 하지 않는다.

### 영상

- 새 종목 10개와 덤벨컬(분류 칩이 바뀜) 영상을 만든다. 영상 프로젝트의 분류 색·라벨 복사본에 두 분류를 더한다.
- 소품: 케틀벨은 분류 색 몸통(원)과 손잡이(고리), 덤벨은 기존 덤벨 원판.
- 옆모습 기준, 래터럴 레이즈만 앞모습(팔을 옆으로 드는 동작).
- 반복 수는 10회(케틀벨 스윙은 15회 × 2초), 원암 동작은 가까운 쪽 팔로 한쪽만 보여준다.

src/timer/                   브라우저 전용: speech.ts(음성), beep.ts(삐 소리), wake-lock.ts, session.ts(진행 중 타이머 모듈 상태)
src/app/timer/page.tsx       목록·편집·실행(쿼리 파라미터, Suspense)

video/src/exercises/*.ts     새 종목 10개

- `src/domain/timer.ts`는 React·브라우저와 무관한 순수 함수라 테스트를 먼저 쓴다.
- 음성·삐 소리·화면 꺼짐 방지는 `src/timer/`에 모아 브라우저 API를 감싼다. `window.speechSynthesis`, `AudioContext`, `navigator.wakeLock`은 이 폴더에서만 쓴다.

## 8. 테스트

- 단위 테스트(먼저 쓴다)
  - timer: 범위 검사, 구간 펼치기(기본·서킷·0초 구간 빼기·마지막 휴식 없음), 총 시간, `positionAt` 경계, `cuesBetween`(한 번만·1.5초 넘으면 버림·3-2-1·절반·마지막 라운드), 프리셋이 모두 유효하고 기본 종목을 가리킴
  - seed: 새 종목 52개, ID 중복 없음, 모든 종목에 가이드, `syncSeedExercises`(빠진 것 더하기, 같은 이름이면 건너뛰기, 분류만 맞추기, 바뀐 것 없으면 같은 객체)
  - store: 기존 데이터를 불러오면 새 종목이 채워지고 저장됨, `saveTimer`·`deleteTimer`, 타이머 참조 검사, 타이머에 쓰인 종목 삭제 거부
  - backup: 타이머 포함 왕복
  - 영상: 새 종목 10개의 제약(손·발 고정 등), 분류 색·라벨이 앱과 같음, 기본 종목 순서와 같음
- 화면 확인(브라우저, 휴대폰 크기): 프리셋 실행과 음성·삐 소리, 일시정지·건너뛰기, 다른 탭에 갔다 오기, 서킷 영상, 뒤로 가기 → 이어하기, 편집·저장·복사·삭제, 새 분류 종목과 영상, 달력 점 7개
- 아이폰 실기기의 음성과 화면 꺼짐 방지는 사용자가 확인한다.
