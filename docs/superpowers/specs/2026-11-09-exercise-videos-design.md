## 1. 목적과 범위

### 목적

등록된 종목을 휴대폰에서 보며 따라 할 수 있는 짧은 영상을 만든다.

- 영상은 동작 그림과 따라하기 카운터(횟수 또는 남은 시간)로 이뤄진다.
- 앱 편집 화면의 ⓘ 가이드에서 바로 재생한다.

### 이번 범위: 시범 5개

분류마다 하나씩 만든다. 사용자가 그림 모양, 속도, 자세를 확인한 뒤 나머지 종목으로 넓힌다.

| 종목 (seed ID) | 분류 | 측정 방식 |
|---|---|---|
| 스쿼트 (`seed-squat`) | #근력운동 | 무게×횟수 |
| 푸시업 (`seed-push-up`) | #맨몸운동 | 횟수 |
| 플랭크 (`seed-plank`) | #코어운동 | 시간(초) |
| 햄스트링 스트레칭 (`seed-hamstring-stretch`) | #스트레칭 | 시간(초) |
| 줄넘기 (`seed-jump-rope`) | #유산소 | 시간(분)·거리 |

### 이번에 하지 않는 것

- 나머지 37개 종목 (시범 확인 후 별도 작업)
- 소리(박자음, 음성 카운트)
- 직접 추가한 종목의 영상
- 실제 사람 영상, AI 생성 영상
- PWA 오프라인 캐시

### 성공 기준

1. 영상 5개가 `public/videos/<seedId>.mp4`로 만들어진다.
   - 720×720, 30fps, H.264, 소리 없음
   - 각 1.5MB 이하
2. 영상의 이름, 분류, 주요 부위, 핵심 포인트가 앱의 `seed.ts`와 글자 그대로 같다.
3. 운동 제약을 모든 프레임에서 지킨다.
   - 스쿼트: 발이 바닥에서 떨어지지 않는다.
   - 푸시업: 손 위치가 변하지 않는다.
   - 플랭크: 버티는 동안 몸이 일직선이다.
   - 스트레칭: 두 발이 고정된다.
4. 앱에서 ⓘ를 열면 영상이 iPhone에서도 카드 안에서 소리 없이 반복 재생되고, 닫으면 멈춘다.
5. 앱의 기존 테스트, 린트, 정적 빌드가 그대로 통과한다.

### 알려진 한계

- 선과 원으로 그린 그림이라 동작의 윤곽만 보여준다. 코치나 실제 시범을 대신하지 못한다.
- 영상 속 한글은 Windows 시스템 글꼴(맑은 고딕)로 그린다. 다른 운영체제에서 다시 렌더링하려면 한글 글꼴이 있어야 한다.
- Remotion은 개인과 3인 이하 회사는 무료다. 그보다 큰 조직이 상업적으로 쓰려면 라이선스가 필요하다.

## 2. 영상 사양

### 공통

- 크기: 720×720 정사각형. 앱 종목 카드 폭에 맞춘다.
- 30fps, H.264 mp4, 소리 없음
- 색
  - 밝은 배경 `#eef0f2`
  - 그림과 글자 `#1b1f24`
  - 보조 글자 `#5e6670`
  - 강조색: 앱의 분류 원판 색
    - 근력 `#d7263d`
    - 맨몸 `#1f5fbf`
    - 코어 `#e0ac00`
    - 스트레칭 `#2e9e5b`
    - 유산소 `#8a939d`

### 시간 구성

| 구간 | 길이 | 내용 |
|---|---|---|
| 제목 | 2초 (60프레임) | 종목 이름, 분류 칩, 주요 부위 |
| 본 동작 | 종목별 (아래 표) | 동작 그림, 카운터, 진행 막대. 화면 아래에 핵심 포인트를 계속 표시 |
| 완료 | 2초 (60프레임) | "완료"와 종목 이름 |

| 종목 | 본 동작 | 카운터 |
|---|---|---|
| 스쿼트 | 10회 × (내리기 2초 + 올리기 1초) = 30초 | `n / 10` (올리기를 마칠 때 1 증가) |
| 푸시업 | 10회 × (내리기 2초 + 올리기 1초) = 30초 | `n / 10` |
| 플랭크 | 자세 잡기 2초 + 버티기 30초 = 32초 | 자세 잡는 동안 "준비", 버티기 중 남은 시간 `0:30`→`0:00` |
| 햄스트링 스트레칭 | 자세 잡기 2초 + 버티기 30초 = 32초 | 플랭크와 같음 |
| 줄넘기 | 30초 (0.5초마다 한 번 점프) | 남은 시간 `0:30`→`0:00` |

진행 막대는 본 동작의 경과 비율을 보여준다. 자세 잡기 구간이 있는 종목은 버티기 구간의 경과 비율을 보여준다.

## 3. 그림 모델

### 뼈대

- 옆에서 본 사람 그림이다. 오른쪽을 바라본다.
- 마디 길이(px)는 다음과 같다. 서 있을 때 키는 약 360px이다.
  - 머리 반지름 22, 목 18, 몸통 120
  - 위팔 70, 아래팔 62
  - 넓적다리 92, 정강이 90, 발 28
- 팔과 다리는 앞쪽(가까운 쪽)과 뒤쪽(먼 쪽) 두 개씩 그린다.
  - 가까운 쪽은 그림 색으로 굵게, 먼 쪽은 연하게(투명도 0.4) 그린다.

### 자세

- 자세는 각 마디의 **절대 각도**(도, +x 방향 기준, 위쪽이 +)로 정한다.
  - 몸통, 머리
  - 팔 두 개의 위팔과 아래팔
  - 다리 두 개의 넓적다리, 정강이, 발
- **기준점(anchor)** 하나를 화면 좌표에 고정하고, 나머지 관절을 이어서 계산한다(정기구학).
  - 기준점 후보: 두 다리 중 하나의 발목이나 발끝, 또는 엉덩이
  - 발목이나 발끝이 기준이면 그 다리 사슬을 거꾸로 올라가 엉덩이를 구한다. 거기서 몸통, 어깨, 머리, 팔, 다른 다리를 계산한다.
- **끝점 고정(IK)**: 손이나 발목이 특정 점에 붙어 있어야 하면, 그 팔다리의 두 마디 각도를 2관절 역기구학으로 다시 계산한다.
  - 굽는 방향(팔꿈치·무릎이 어느 쪽으로 접히는지)은 종목 정의에 둔다.
  - 목표가 닿지 않는 거리면 목표 방향으로 쭉 편 팔다리를 쓴다.

### 움직임

- 종목은 키프레임 자세 몇 개와 그 사이 시간으로 정의한다.
- 키프레임 사이의 각도와 기준점 위치는 ease-in-out(사인 곡선)으로 보간한다.
- 스트레칭의 버티기 구간에는 몸통 각도를 ±0.6도, 4초 주기로 흔들어 숨쉬기를 표현한다. 고정 제약(손·발·일직선)은 그대로 지킨다. 플랭크는 흔들지 않는다(검토 #1).

### 종목별 정의

| 종목 | 기준점 | 키프레임 | 고정 | 소품 |
|---|---|---|---|---|
| 스쿼트 | 가까운 쪽 발목(바닥) | 선 자세 ↔ 앉은 자세(넓적다리가 바닥과 평행, 몸통 약 45° 숙임) | 두 발목이 바닥 고정(먼 쪽 다리는 IK로 발목을 바닥에 붙임). 두 손은 어깨 뒤 바벨을 잡음(IK) | 어깨 위 바벨(회색 막대, 끝에 분류 색 원판) |
| 푸시업 | 가까운 쪽 발끝(바닥) | 팔 편 자세 ↔ 가슴이 바닥 가까이 | 두 손이 어깨 아래 바닥에 고정(IK). 몸은 일직선 | 없음 |
| 플랭크 | 가까운 쪽 팔꿈치(바닥) | 무릎 대고 엎드린 자세 → 팔꿈치 플랭크 | 팔꿈치와 아래팔이 바닥에 고정. 발끝은 바닥에 붙인다. 버티는 동안 어깨·엉덩이·발목이 일직선이고 숨쉬기 흔들림은 없다 | 없음 |
| 햄스트링 스트레칭 | 먼 쪽(뒤) 다리 발목(바닥) | 선 자세 → 앞다리를 편 채 고관절에서 숙인 자세 | 가까운 쪽(앞) 다리 발목은 IK로 바닥에 고정, 뒤 발목은 기준점. 등은 편 채(몸통이 직선) | 없음 |
| 줄넘기 | 엉덩이(위아래로 움직임) | 착지(무릎 살짝 굽힘) ↔ 공중(발끝이 바닥에서 약 18px) | 손은 엉덩이 옆 | 손에서 손으로 몸을 도는 줄(회전 위상에 따라 머리 위나 발아래로 지나는 곡선) |

## 4. 프로젝트 구조

`video/`는 앱과 따로 있는 npm 프로젝트다. 앱의 의존성, 빌드, 린트에 영향을 주지 않는다.

```
video/
  package.json        remotion@4.0.538, @remotion/cli, @remotion/bundler, @remotion/renderer, react 19, typescript, vitest
  tsconfig.json
  src/
    index.ts          registerRoot
    Root.tsx          종목마다 Composition 등록. id는 seed ID, 길이는 종목 정의에서 계산
    figure/
      geometry.ts     정기구학, 2관절 IK, 자세 보간
      Figure.tsx      관절 좌표를 SVG로 그린다
    exercises/
      squat.ts pushup.ts plank.ts hamstring.ts jumprope.ts
      index.ts        VIDEO_EXERCISES: seed ID → 종목 정의
    scenes/
      ExerciseVideo.tsx   제목 → 본 동작 → 완료
      counter.ts          프레임 → 카운터 표시값, 진행 비율 (순수 함수)
  scripts/
    render.ts         모든 종목을 ../public/videos/<seedId>.mp4로 렌더링하고 크기·길이를 출력
                      (코덱 h264, CRF 28, 소리 트랙 없음. 설정 파일 대신 이 스크립트에 둔다)
```

### 앱 데이터 공유

- 종목 이름, 분류, 주요 부위, 핵심 포인트는 앱의 `src/domain/seed.ts`를 상대 경로로 import해 쓴다. 따로 복사하지 않는다.
- `seed.ts`는 `./types`를 타입으로만 import하므로 영상 쪽 번들에 zod가 들어가지 않는다.

### 명령 (`video/` 안에서 실행)

| 명령 | 내용 |
|---|---|
| `npm run studio` | 브라우저 미리보기 |
| `npm run render` | 5개 렌더링 |
| `npm test` | 단위 테스트 |

### 앱 설정 변경

- 앱의 `tsconfig.json`에서 `video`를 제외한다(`exclude`).
- ESLint 설정의 무시 목록에 `video/**`를 추가한다.

## 5. 앱 연동

### `src/domain/videos.ts`

- `GUIDE_VIDEOS: ReadonlySet<string>`: 영상이 있는 seed ID 5개
- `guideVideoSrc(id: string): string | undefined`: 영상이 있으면 `/videos/<id>.mp4`, 없으면 `undefined`

### 목록과 파일의 일치

앱 단위 테스트로 양쪽을 검사한다.

- `GUIDE_VIDEOS`의 ID는 모두 `SEED_EXERCISES`에 있다.
- `GUIDE_VIDEOS`의 ID마다 `public/videos/<id>.mp4` 파일이 있다.
- `public/videos/`의 mp4는 모두 `GUIDE_VIDEOS`에 있다(고아 파일 없음).

### 편집 화면 ⓘ 가이드 패널

- 영상이 있는 종목이면 핵심 포인트 위에 `<video>`를 둔다.
  - 속성: `src`, `muted`, `loop`, `playsInline`, `controls`, `preload="metadata"`
  - 정사각형으로 패널 폭에 맞춘다(`aspect-square w-full`).
- 패널이 열릴 때 요소가 생기며 자동재생된다. 닫히면 요소가 사라져 재생이 멈춘다.
- 시스템의 "동작 줄이기"(`prefers-reduced-motion: reduce`)가 켜져 있으면 자동재생하지 않는다. 컨트롤로 재생한다.
- 영상이 없는 종목은 지금과 같다.

## 6. 테스트와 확인

### 영상 프로젝트 단위 테스트 (Vitest)

- `geometry`
  - 모든 마디 길이가 정의한 길이와 같다(오차 0.01px).
  - IK
    - 닿는 거리면 끝점이 목표와 같다(오차 0.5px).
    - 닿지 않는 거리면 목표 방향으로 편 팔다리다.
    - 굽는 방향 지정을 따른다.
  - 보간: t=0이면 첫 키프레임, t=1이면 마지막 키프레임과 같고, 중간값이 두 값 사이에 있다.
- 종목 제약 (모든 프레임 검사)
  - 스쿼트: 두 발목의 y가 바닥과 같다.
  - 푸시업: 두 손의 좌표가 프레임마다 같다.
  - 플랭크: 버티는 동안 어깨·엉덩이·발목이 일직선이다. 엉덩이의 직선 이탈이 4px 이하다.
  - 스트레칭: 앞 발뒤꿈치와 뒤 발목이 고정된다.
  - 모든 종목: 어떤 관절도 바닥 아래로 내려가지 않는다.
- `counter`
  - 반복 종목
    - 첫 프레임은 `0 / 10`
    - 첫 반복을 마친 프레임에서 `1 / 10`
    - 마지막 프레임은 `10 / 10`
  - 시간 종목
    - 자세 잡기 중에는 "준비"
    - 버티기 시작은 `0:30`, 끝은 `0:00`
    - 진행 비율은 0에서 1까지
- 종목 정의와 앱 seed: `VIDEO_EXERCISES`의 ID가 모두 seed ID다.
